# 全錶款目錄：官網資料與發布檢查

2026-09-07 新增 `catalog.html`，在既有 3D 工作台頂端及故事入口提供連結。

## 完成內容

- 163 個官方腕錶商品頁、16 品牌、1,196 款整錶搭配，含 Samurai 與手錶分類漏列的 ONOLA。售完但仍公開的商品保留並標示狀態。
- 獨立照片相簿、逐款選項、實際售價、官網原價（僅大於售價時顯示）、庫存快照、規格與原文介紹。
- 搜尋、品牌／客製系列篩選、排序、收藏系列、複製所選搭配、可分享的商品與選項網址。
- 手機保留上方照片，選項在下方獨立捲動。桌機雙欄，可使用鍵盤、Esc、瀏覽器返回。
- `index.html?series=MM#configHead` 等連結直接開啟對應的既有 3D 系列。工作台移除未經官方確認的零件加價與估算總價，改為搭配另詢價。

## 資料口徑

官方全商品 292 筆與 sitemap 完全一致；手錶分類 176 筆排除 14 筆純配件／服務，補入 1 筆漏列腕錶，共 163 筆。完整性證據見 [COMPLETENESS.md](catalog/COMPLETENESS.md)。

官方共有 1,199 個 variant：扣掉 MM Buckle、Carbon 選配真碳纖圈兩個獨立配件，以及 Datejust 一個客製洽詢選項，為 1,196 個整錶搭配。Datejust 客製需求保留在說明，不冒充已確定的實錶。Parnis 等「加購錶帶」選项的價格包含整錶，因此保留。

`variant.price` 以分為單位，除以 100 才是 TWD。每個選項直接使用官方價，不從通用加價表推算。38 筆缺圖和 2 筆不準確圖片綁定使用同商品官方相簿修正，見 [圖片證據](catalog/variant-image-overrides.json)。多個選項共用照片時，介面說明錶帶／加購内容依所選搭配。

## 範圍與維護

此更新完成全錶款**實拍目錄**。既有 6 系列具備 3D 搭配示意；其餘商品沒有製作或假冒可旋轉的 3D 模型。Blender 5.2 已確認可用，本次未用其製作模型。

價格與庫存是 2026-09-07 查核快照，不是即時後台串接；介面標明核對日並連到官網訂購。完整公開來源快照保存在工作目錄 `ichco-catalog-work`，以 `python scripts/build_catalog.py <snapshot_dir>` 可重建資料（需要 BeautifulSoup）。更新時須重新取得所有商品與各頁資料，重新核對配件、圖片修正及規格證據，再執行功能與視覺 QA。

本次使用者已明確授權完成後自行上架，因此驗證完成後可推送既有 GitHub Pages。
