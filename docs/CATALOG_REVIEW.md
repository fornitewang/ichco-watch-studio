# 全錶款目錄：官網資料與發布檢查

2026-09-07。163 個官方腕錶商品頁、16 品牌、1,194 組整錶配置，含 Samurai 與手錶分類漏列的 ONOLA。售完但仍公開的商品保留並標示狀態。

## 可選搭配

- 每款只提供該商品實際存在的完整配置；選項名稱以中文呈現，原始名稱另存於資料供核對。固定機芯等單一值顯示文字，不產生假的切換按鈕。
- 官網有多欄選配的商品，依完整配置限制後續選項。換型號後原機芯或錶帶沒有對應組合，就清空要求重選；不默默換另一款。未選完不顯示確定總價，分享網址也保留待選狀態。
- 所選款式、共用參考照片與系列相簿分別標示。相簿只供看照片，不會更改配置或售價。缺獨立照片與圖片載入失敗另外提示。
- 未列出的錶殼、指針或其他配件需求使用獨立詢問區；複製文字明示整錶價不含額外需求，需確認能否製作與最終報價。
- 3D 預設是系列外型示意。只有主動開啟「概念搭配（需另外確認）」才可自由改零件；切換系列會重置。沒有官方依據的搭配不承諾價格、防水或配件適用性。

詳細規則和逐商品範圍見 [配置流程審查](COMPATIBILITY_REVIEW.md) 及 [逐商品可選項審查](catalog/CAPABILITY_AUDIT.md)。

## 資料口徑

官方全商品 292 筆與 sitemap 完全一致；手錶分類 176 筆排除 14 筆純配件／服務，補入 1 筆漏列腕錶，共 163 筆。見 [完整性](catalog/COMPLETENESS.md)。

官方 1,199 個 variant，扣掉 MM Buckle、Carbon 真碳纖圈、Pagani PD-1661 單獨鋼帶、PD-1651 單獨鋼帶四筆配件，以及 Datejust 一筆客製洽詢，保留 1,194 組整錶／配套。本輪修正先前漏排兩筆鋼帶、誤報 1,196 組的問題。Parnis 等「加購錶帶」價格包含整錶，因此保留；EOEO 與 Flieger 的兩個概括錶帶選項另標需補充內容。

`variant.price` 除以 100 才是 TWD。每個配置直接使用官方完整售價，不套通用加價表。38 筆缺圖和 2 筆不準確圖片綁定使用同商品官方相簿修正，見 [圖片證據](catalog/variant-image-overrides.json)。共用照片只供參考，不宣稱呈現所有加購內容。

## 驗證

- 163 商品與 1,194 組配置逐筆核對官方來源、價格、選项及圖片來源；見 [逐款表](catalog/PRODUCT_QC.md) 和 [資料報告](catalog/data-audit.json)。資料對應檢查不等於逐張外觀目視驗證。
- Chrome 透過實際 DOM 選單走過全部 1,194 組：可達、完整售價、圖片 ID、網址與複製狀態通過。此全量檢查用替代圖片隔離網路，照片本身另做實際載入抽查。
- 1440、390、320 視口的切換、清空、重選、分享重載、共用照片／相簿、手機捲動，以及六系列 3D 預設／概念模式共 56 項通過，無 JS 錯誤。
- 獨立驗收包含售完與未列組合的不同狀態、單一配置、固定機芯、實際剪貼簿、缺圖與主圖失敗及恢復。證據見 [獨立 QA](catalog/COMPATIBILITY_QA.md)。
- 163 張封面皆本機 WebP；其他官方照片按需載入，部分已備份本機。前輪確認 872 個本機 WebP 無損毀，此輪未更動照片檔。
- 前輪搜尋、篩選、收藏、鍵盤等檢查通過；本輪未更動這些功能。3D 幾何與內嵌圖資未修改。

## 範圍與維護

這是全錶款實拍目錄，並非 163 個新 3D 模型。既有六系列只作外型與概念搭配示意；從目錄提供 3D 入口的配置，目前僅有已核對對應的 MM 黑 NH38，避免白面 NH35 被帶到不同外型。

價格與庫存是 2026-09-07 查核快照，頁面標核對日期並連到官網確認。原始快照位於本機 `ichco-catalog-work`；使用 `python scripts/build_catalog.py <snapshot_dir>` 可重建資料（需 BeautifulSoup）。更新前須重新取得商品及完整變體資料，重核配件、图片修正和規格來源，再執行搭配與視覺 QA。

使用者已授權完成後自行上架，沿用既有 GitHub Pages。
