# 首頁分層故事與手機入口

2026-09-07。使用者明確要求直接改造既有 GitHub Pages 網站，方便在手機上查看；延續完成後自行發布的授權。

## 結果與架構

首頁 `index.html` 改為 300vh 的輕量分層故事，CSS sticky 保持舞台，ScrollTrigger `scrub:true` 驅動 Y／Z 位移、縮放及機芯整層旋轉。可向上重組或使用一鍵拆解。位移取自實際圖片容器尺寸，刷新視口重算；手機橫向、短螢幕各有配置。標題在手機展開時淡出，尾段顯示各層標籤。

原 2.65 MB 工作台保留為同層 `studio.html`。只變更品牌回首頁、favicon、手機預覽頂距與窄螢幕邊距；模型建構、材質、AR、內嵌影像原樣。目錄兩個 3D 入口和逐款預覽指向 studio，頁首品牌回新首頁。旧 series／artilt／ardebug／mpcpu 參數及 #configHead 保留轉址；`?v=` 正常開首頁。

首頁不載入 Three.js、HDRI 或 MediaPipe，GSAP 與 ScrollTrigger 使用本機同版依賴。未修改 163 商品／1,194 配置資料與價格邏輯。

## 素材與外觀 QC 範圍

專案、桌面及下載中未找到原先提到的五張 PNG，因此從既有 MM_PRESET 模型輸出五層，沒有製作虛構官網照片或假冒實際機芯結構。

| 圖層 | 來源 | 審查結果 |
|---|---|---|
| 鏡面 | 既有 crystal 與透明亮邊 | 同相機／同畫布，透明度保留 |
| 指針 | 時、分、秒針及中心軸 | 原模型形狀／對位不變 |
| 錶盤 | 盤面、時標、開心窗邊框 | 沿用原模型圖資，沒有更改印字或比例 |
| 機芯示意 | 原簡化背面機芯與開心窗擺輪／夾橋 | 明確標示示意，不當作原廠 NH38 輪系 |
| 外殼與錶帶 | 原殼體、錶圈、護橋、內座、底蓋、錶帶 | 同投影；分層後重新計算陰影，無殘留指針影子 |

五層均為 1000×1200 RGBA，未獨立裁切。以黑／白底雙次原 renderer 渲染取得 alpha，維持原 HDRI 與色調。`assembled.png` 是同五層原位合成，與零進度靜態對位相同；與完整原模型可見區 RGB MAE 0.763/255，差異來自平面合成遮擋、抗鋸齒及分層陰影。這是與既有模型的對位審查，**不等同與原廠零件逐一核對**。既有模型細節限制延續 [MM_REFERENCE_REVIEW.md](MM_REFERENCE_REVIEW.md)。

## 功能与容錯

- 組裝、半開、全開、倒捲與一鍵操作；1440×1000、390×844、320×568、844×390 目視檢查。
- 縮放只變 transform；overflow:clip 放在外層舞台，排除透明畫布造成的橫向 scroll bounds，實際可見零件沒有被裁切。
- 減少動態設定變更能即時切換靜態／動畫；靜態不保留 300vh 空白。無 JavaScript、GSAP 載入失敗或單層圖片失敗都有完整靜態圖與可用導航。
- 官網款式卡顯示系列價範圍，連結到該商品實拍／選項；沒有用分層概念搭配價格冒充可訂購商品。
- 原工作台手機 mini 改依實測 header 高度定位（61.5px 向上取整為 62px），320px 左右各 12px；觸控橫拖與縱向捲頁、收合功能保留。

原始 QA：`ichco-catalog-work/exploded/qa`、`qa-independent`。報告快照位於 `docs/home/`。五張圖與 fallback 合計 912,413 bytes；原本四個巨大內嵌影像行與三段腳本已分別確認圖資一致及語法通過。主程式僅手機 pin 頂距有明確差異，另兩段腳本完全一致。

最終驗收：首頁17項状态／容錯檢查通過；手機實際觸控捲動、旋轉視口重算及中段重載通過；獨立整合90項全通，零 JS／console errors。320px實際頁寬與捲動寬均320，預覽x12/right308、header61.5／pin62。測試環境為Chrome及iPhone尺寸／觸控模擬，未宣稱Safari實機測試。
