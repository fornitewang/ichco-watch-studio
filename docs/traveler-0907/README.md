## 互動
- 平時沿目前高度左右走動，腿與自由手臂交錯擺動，行李輪轉動。
- 滑鼠／觸控抓取；慢放留在新高度，快速甩放有慣性、重力及邊緣回彈，落地後恢復走路。
- 單點提示，雙擊／雙點才開官方行李箱集合頁（新分頁）。
- 鍵盤 Enter／Space 開啟，方向鍵挪動。按住鍵不會重複開頁。
- 右下小旅人選單可暫停、收起／叫回；偏好只保存在本分頁 sessionStorage。
- 商品詳情與隱藏分頁暫停 RAF 和步態；減少動態偏好下不自動走動、不拋擲，仍可直接拖放。
